1. Ringkasan & Arsitektur Sistem

Aplikasi ini dirancang khusus untuk memonitor dan mengontrol komputer dalam jaringan lokal (LAN / Wi-Fi lokal / VLAN / Intranet) secara real-time tanpa ketergantungan pada server cloud luar:

Server (Admin Dashboard)

Pusat kontrol berbasis web responsif yang diakses via browser (Chrome, Edge, Firefox). Menampilkan metrik hardware (CPU %, RAM %, Disk %), thumbnail live screen, remote control interaktif, task manager proses, dan terminal shell.

Client (Agent)

Berjalan sangat ringan di latar belakang pada setiap PC target (Windows 10/11 & Linux Mint 22 / Ubuntu 22.04 LTS). Dilengkapi icon System Tray dinamis, auto-reconnect, serta auto-discovery via UDP broadcast.

2. Fitur Pengecekan Port Otomatis (Auto Port Detection)

Apakah server mengecek otomatis mana port yang kosong?

YA, 100% Otomatis! Server mendeteksi apakah port default sedang dipakai oleh proses lain (seperti svchost, Laragon, Apache, IIS) dan otomatis berpindah ke port berikutnya yang aman (contoh: 8001, 8002, dst).

  1. Deteksi Cerdas: Saat server dinyalakan, modul port_utils.py memeriksa ketersediaan port TCP 8000.
  2. Identifikasi Proses: Jika port terpakai, sistem membaca nama aplikasi dan PID pemakainya (contoh: Warning: Port 8000 in use by svchost.exe PID 5636).
  3. Auto Fallback: Server otomatis mengikat (bind) ke port kosong berikutnya (default: 8001).
  4. UDP Beacon: Server menyiarkan sinyal UDP di port 8002 untuk mengumumkan port aktifnya kepada seluruh client di subnet LAN.

3. Cara Mengatur Server IP & Port pada Client

Tersedia 4 metode fleksibel untuk mengatur alamat server pada client:

Cara A - Installer

Installer Interaktif

Jalankan install_windows.bat atau install_linux.sh. Anda akan ditanya IP & Port server secara langsung di terminal.

Cara B - Auto

Auto-Discovery

Cukup tekan ENTER saat instalasi (kosongkan IP). Client akan mencari sinyal beacon UDP dari server di LAN secara instan (1 subnet).

Cara C - Edit File

Manual config.json

Buka file client/config.json dengan Notepad / Text Editor, masukkan nilai server_ip dan server_port.

Cara D - UI Settings

Antarmuka GUI

Double-click ikon System Tray atau jalankan settings.bat / settings.sh untuk membuka jendela pengaturan IP/Port grafis yang tersimpan otomatis.

4. Panduan Instalasi Client (Windows 10 / 11)

Standalone Executable, System Tray, dan Autostart

A. Pilihan Metode Instalasi Windows

Opsi 1: Standalone EXE (LANRemoteClient.exe) - 100% Offline & Tanpa Python Paling Mudah

Cocok untuk PC client yang tidak memiliki Python dan tanpa akses internet:

  1. Salin file client/LANRemoteClient.exe (31.8 MB) dan client/config.json ke folder PC target (misal C:\Program Files\LANClient\).
  2. Klik ganda LANRemoteClient.exe.
  3. Client langsung aktif di background dan ikon monitor hijau muncul di System Tray!
Opsi 4: Service / Task Scheduler (install_service.bat) - Mendukung Lock Screen (Win+L) Akses Penuh Seperti AnyDesk

Klik kanan client/install_service.bat → pilih "Run as administrator".

Skrip ini mendaftarkan client ke Windows Task Scheduler dengan Hak Akses Tertinggi (/rl highest) dan mengaktifkan Software SAS. Komputer target tetap dapat diakses dan dilihat layarnya saat dalam keadaan Lock Screen / Layar Kunci!

B. Fitur System Tray & Autostart Windows

Tampilan System Tray Windows

Ikon monitor otomatis muncul di Taskbar pojok kanan bawah (Notification Area dekat jam Windows):

  • 🟢 Hijau: Terkoneksi ke Server Admin
  • 🔴 Merah: Reconnecting / Mencari Server

Menu Klik Kanan: Cek Status, Salin Device ID, Buka Web Dashboard Admin, dan Keluar (Exit).

Dua Metode Autostart Windows

Cara A (Rekomendasi - Menembus Lock Screen):

Jalankan install_service.bat sebagai Administrator.

Cara B (Folder Startup Standar):

Tekan Win+R → ketik shell:startup → Paste shortcut LANRemoteClient.exe.

5. Panduan Instalasi Client (Linux Mint 22 / Ubuntu 22.04 LTS)

Lengkap dengan System Tray Panel & Autostart Login
Linux Mint (Cinnamon/MATE/XFCE) & Ubuntu

A. Fitur & Tampilan Ikon System Tray di Linux Mint

Ikon monitor dinamis akan langsung muncul di panel system tray pojok kanan bawah Linux Mint (Cinnamon) atau top bar Ubuntu (GNOME):

Titik Hijau (Connected): Terhubung aktif ke Server Admin
Titik Merah (Reconnecting): Sedang mencari server

Menu Klik Kanan pada Ikon Tray:

• Status : Connected / Reconnecting
• ID : node-50e5498494ad (Device ID PC)
• Server : 192.168.8.167:8001
------------------------------------
• Buka Web Dashboard Admin (membuka browser otomatis)
• Salin Device ID (menyalin ID ke clipboard)
------------------------------------
• Keluar (Exit Client)

B. Install Dependensi System Tray (pystray) di Linux Mint

Jalankan perintah berikut di Terminal komputer Linux Mint Anda: 

# 1. Pasang paket sistem panel AppIndicator & Tkinter:
sudo apt update && sudo apt install -y python3-gi python3-gi-cairo gir1.2-ayatanaappindicator3-0.1 python3-tk

# 2. Pasang pystray via pip:
pip3 install pystray --break-system-packages
Penting: Mengapa Ikon System Tray Tidak Muncul?

Di Windows 10/11: Taskbar secara otomatis menyembunyikan ikon aplikasi baru ke menu Hidden Icons (tanda panah atas ^ di sebelah kiri jam). Klik tanda ^ untuk melihatnya. Agar selalu terlihat, buka Windows Settings → Personalization → Taskbar → Other system tray icons dan aktifkan ke "On".

Di Linux Mint / Ubuntu: Jangan pernah menjalankan client menggunakan sudo ./run_client.sh! Akun root tidak memiliki akses ke sesi DBus & X11 desktop user. Selalu jalankan sebagai user biasa: ./run_client.sh.

C. Cara Mengaktifkan Autostart saat Boot / Login di Linux Mint

Cara 1 (Rekomendasi 1-Klik)

Menggunakan Skrip Otomatis setup_autostart_linux.sh

Buka terminal di folder client dan jalankan:

chmod +x setup_autostart_linux.sh
./setup_autostart_linux.sh

Skrip otomatis mendaftarkan file launcher ke ~/.config/autostart/lan-remotedesktop-client.desktop. Skrip ini aman dijalankan oleh user biasa maupun dengan sudo (tetap menargetkan home user non-root).

Cara 2 (GUI Menu Linux Mint)

Melalui Menu Startup Applications Bawaan Linux Mint

  1. Buka Menu Linux Mint → Cari dan buka "Startup Applications" (Aplikasi Awal Mula).
  2. Klik tombol + (Tambah) di bagian bawah → pilih "Custom command".
  3. Isi data form:
    • Name: LAN Remote Client
    • Command: Klik Browse → pilih file run_client.sh
    • Startup Delay: 2 detik
  4. Klik Save. Selesai!

Menjalankan Manual Kapan Saja

Jalankan launcher yang sudah disiapkan:

chmod +x run_client.sh
./run_client.sh

Opsi Headless (--no-tray)

Untuk PC server Linux tanpa monitor/desktop GUI:

python3 client.py --no-tray

6. Panduan Instalasi Server Admin (Windows 10 / 11)

Jika PC Administrator utama menggunakan Windows:

  1. Pastikan Python 3.9+ sudah terpasang.
  2. Klik ganda file install_admin_server.bat untuk memasang kebutuhan server (FastAPI, Uvicorn, websockets, dll).
  3. Klik ganda run_server.bat untuk menyalakan server.
  4. Buka browser dan kunjungi: http://localhost:8001 (atau port yang tertera pada console).
  5. Pada saat pertama kali dibuka, buat username dan password administrator baru.

7. Panduan Instalasi Server Admin di Ubuntu Server (Headless 24/7)

Sangat Direkomendasikan untuk Kantor, Warnet, Lab Komputer

Server remote desktop ini sepenuhnya "Headless" (tidak memerlukan monitor/desktop GUI) dan dapat berjalan 24 jam non-stop sebagai Systemd Service di Linux: 

# OPSI 1: Pasang Systemd Service Langsung (1-Klik):
chmod +x install_server_service.sh uninstall_server_service.sh
sudo ./install_server_service.sh

# Cek Status Service & Real-time Logs:
sudo systemctl status lan-remote-server
sudo journalctl -u lan-remote-server -f

# Hapus Service Kapan Saja:
sudo ./uninstall_server_service.sh

Buka browser dari komputer mana saja dalam jaringan LAN: http://[IP-UBUNTU-SERVER]:8001.

8. Manajemen Password & Reset Console

Jika Lupa Password Admin:

Jalankan skrip reset console yang aman tanpa merusak konfigurasi client:

Windows: python reset_password.py
Linux: ./reset_password.sh

Standar Keamanan

Password dienkripsi menggunakan PBKDF2-HMAC-SHA256 dengan 100.000 iterasi dan unique salt. Sesi login dilengkapi remember me 30 hari dengan session token acak.

10. Tanya Jawab & Troubleshooting Jaringan LAN

Q: Mengapa pada Linux Mint muncul [Errno 111] Connect call failed?

A: Terjadi jika client mencoba konek ke 127.0.0.1 (localhost Linux sendiri) karena Server Admin berada di PC lain (misal di PC Windows 192.168.8.167:8001). Solusinya: masukkan IP server admin yang tepat saat instalasi atau di config.json.

Q: Apakah beda VLAN (misal VLAN 5 dan VLAN 8) bisa saling terkoneksi?

A: BISA untuk koneksi WebSocket TCP unicast! Namun broadcast UDP otomatis (auto-discovery port 8002) biasanya diblokir antar VLAN oleh router / switch managed. Oleh karena itu, jika PC client berada di beda VLAN/subnet dengan server, gunakan input IP Manual pada client (misal: ws://192.168.8.167:8001).

Q: Mengapa saat Windows terkunci (Lock Screen / Win+L) remote desktop biasa tidak bisa melihat layarnya?

A: Arsitektur keamanan Microsoft Windows memisahkan desktop normal dari Secure Desktop (Winlogon). Software biasa non-admin diblokir dari merekam Lock Screen. Solusinya: Pasang client dengan install_service.bat (Run as Administrator) agar didaftarkan dengan hak tertinggi (/rl highest) sehingga Lock Screen dapat diakses penuh seperti AnyDesk/RustDesk.

11. Panduan Lengkap Uninstall (Server & Client)

Pencopotan bersih untuk Windows 10/11 & Linux Mint / Ubuntu
Uninstall Admin Server

Menghentikan proses server, menghapus shortcut Desktop & Startup, menghapus tugas Task Scheduler, dan membersihkan aturan Firewall Windows / UFW.

Windows 
# Klik kanan -> Run as administrator:
uninstall_admin_server.bat
Linux (Ubuntu / Mint) 
chmod +x uninstall_admin_server.sh
sudo ./uninstall_admin_server.sh
Uninstall Client Agent

Menghentikan agen client di latar belakang, mencopot pendaftaran autostart saat PC booting, dan memulihkan kebijakan sistem Windows ke standar.

Windows 
# Buka folder client -> Run as administrator:
client\uninstall_windows.bat
Linux (Ubuntu / Mint) 
cd client
chmod +x uninstall_linux.sh
./uninstall_linux.sh
